SOULMATE MINI APP (v1) - лента анкет на весь экран
===================================================

Файлы: index.html, style.css, app.js, config.js (обычный JS без библиотек).
Весь «умный» код (подбор анкет, лимиты, проверки, мэтчи) на сервере в Worker; в приложении только отображение.

1) ПУБЛИКАЦИЯ ПРИЛОЖЕНИЯ
   - config.js: адрес Worker уже указан (https://soulmate-bot.lostbirdsoft.workers.dev). Меняй только его.
   - Выложи папку miniapp/ на свою публичную площадку тем же конвейером, что шашки (минификация и обфускация app.js и style.css допустимы).
   - Адрес должен быть https и открываться в браузере. Запомни его, он понадобится в п. 2.

2) ВКЛЮЧЕНИЕ (в config.js бота, не в этой папке)
     MINIAPP_ENABLED: true,
     MINIAPP_URL: "https://твой-адрес/soulmate/",   // с https и тем же адресом, где лежит index.html
   Затем: npm run deploy, потом один раз открыть https://soulmate-bot.lostbirdsoft.workers.dev/setup?key=ТВОЙ_WEBHOOK_SECRET
   (она ставит кнопку меню чата на приложение). В меню бота появится кнопка «📱 Додаток» (у человека после /start или любого действия в меню).
   Запросы к API принимаются только с адреса из MINIAPP_URL.

3) ВЫКЛЮЧЕНИЕ
     MINIAPP_ENABLED: false, npm run deploy и снова открыть /setup?key=... (вернёт обычную кнопку меню чата).
   API при этом сразу отвечает «выключено», а кнопка в меню бота пропадает.

4) КАК РАБОТАЕТ ЛЕНТА
   - прокрутка вверх-вниз между анкетами; прокрутка вниз без лайка = пропуск (как 👎, анкета вернётся по правилам остывания);
   - ❤️ или двойное касание = лайк; 🚩 = жалоба; свайп вбок = следующее фото или видео; касание текста «о себе» раскрывает его;
   - взаимный лайк показывает «Це метч!» с кнопкой написать (если у человека есть username) и дублируется в боте.
   - зайти может только тот, кто уже создал анкету в боте.

5) ФОТО И ВИДЕО
   Файлы отдаются по подписанным ссылкам /m/... из R2: копия создаётся при первом показе (берётся у Telegram), дальше раздаётся из R2.
   Копии удаляются при смене фото и удалении аккаунта. Ссылки живут MINIAPP_MEDIA_TTL_HOURS часов (по умолчанию 6).

ФЛАГИ: MINIAPP_ENABLED, MINIAPP_URL, MINIAPP_FEED_BATCH (5), MINIAPP_MEDIA_TTL_HOURS (6), MINIAPP_AUTH_MAX_AGE_HOURS (24).

6) РЕДАКТИРОВАНИЕ АНКЕТЫ (v22)
   - В ленте справа сверху кнопка 👤 открывает экран «Моя анкета» (кнопка «Назад» Telegram и ✕ закрывают; при несохранённых правках спросит).
   - Поля: имя, возраст, «я» (пол), «шукаю», город (кнопки топ-городов или своё название), «про себе» (до 300), интересы (готовые + свои, до 5).
     Сохраняется только изменённое, кнопкой «Зберегти». Правила те же, что в боте; сервер проверяет всё заново.
   - Возраст нельзя менять, если в боте указана дата рождения с годом (он считается по ней).
   - Фото: ＋ добавить (приложение сжимает до ~1280 px; сервер на секунду отправляет файл в чат человека, берёт file_id и сразу удаляет сообщение),
     ✕ удалить (последнее обязательное фото удалить нельзя), ★ сделать главным. Видео добавляется только в боте.
   - Флаги (необязательны, значения по умолчанию уже в src/flags.js):
       MINIAPP_EDIT: true,            // false — кнопка 👤 пропадает, API редактирования отвечает «выключено»
       MINIAPP_UPLOAD: true,          // false — без загрузки новых фото из приложения (удалять и менять порядок можно)
       MINIAPP_UPLOAD_MAX_MB: 6,
   - Миграция БД не нужна. Нужно выложить новую папку miniapp/ на хостинг и сделать npm run deploy (/setup заново не нужен).
